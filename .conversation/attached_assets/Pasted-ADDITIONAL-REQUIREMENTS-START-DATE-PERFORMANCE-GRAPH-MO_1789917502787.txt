47. TARGET VS ACTUAL LOGIC

The application must maintain TWO separate datasets:

TARGET PERFORMANCE

and

ACTUAL PERFORMANCE

Target Performance:

Mathematical projection assuming the configured target is achieved.

Actual Performance:

Real results entered by the user.

Never overwrite Target Performance with Actual Performance.

This separation is critical for analytics.

⸻
